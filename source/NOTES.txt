Mulberry Bush web app - how it was built
----------------------------------------
../traced/index.html   the finished single-file app (open it in a browser)
../index.html      the site's home page (written by hand; its pictures are in ../img/)
app.src.html       the app without its data; the build pastes the packed film in at /*__ASSETS__*/
scripts/           Python (numpy + opencv) used to trace the film:
  runall.py        traces every drawing (12 per second) into colour regions  [slow: ~1 hour]
  dimrun.py        special pass for the under-exposed opening seconds
  titlerun.py      title cards: one tracing per card plus a fade value per letter per frame
  part.py/repack.py  clean-up and simplification of the traced shapes
  media_fix.py     hand-checked table of which drawing medium is on screen at each beat
  pack.py          packs everything and writes ../index.html
  audio1/2.py      found the beat grid and chord pattern of the original soundtrack
data/              intermediate results, enough to re-run pack.py without re-tracing
The scripts were run from a working folder laid out as: film.mp4 and the data/ files directly in it,
scripts/ and app/app.src.html beneath it (common.py derives that folder as S). Restore that layout to re-run;
pack.py's output path is written near its end.
To change only music or page behaviour: edit app.src.html, then re-run pack.py (about a minute).

Round the Mulberry Bush (the reinterpretation, nothing traced)
--------------------------------------------------------------
../round/round.src.html   the whole piece in one file: dancers, wheel, band and page (edit this)
build_round.py            copies it to ../round/index.html and writes ../artifact/round-the-mulberry-bush.html for publishing
Open round/index.html#t40 to look at the moment forty seconds in, or #wheel to start in hands-on mode.
build.py                  the same job for the traced version (app.src.html + data/assets.js)

Making-of report
----------------
../report/report.src.html   the report (edit this); its images are in ../report/img/
build_report.py             writes ../report/index.html (standalone) and ../artifact/making-of.html (images embedded, for publishing)
favicons/                   one SVG icon per page; each build script embeds its icon in the stand-alone page (not in the artifact copy)

Trailer (../trailer/mulberry-bush-trailer.mp4, 30 seconds)
----------------------------------------------------------
trailer/cdp.py          talks to a local headless Edge started with --remote-debugging-port=9333 on the page to capture
trailer/cap_traced.py   saves one verse of the traced page as frames, and its soundtrack rendered offline
trailer/cap_round.py    the same for two stretches of Round the Mulberry Bush
trailer/compose.py      cuts film clips, the captured frames and captions together, mixes the sound and encodes with ffmpeg
These were run from a scratch folder holding the film, an ffmpeg binary and the Python libraries; the paths at the top of each need changing to run them again.
